# 🐾 My Pet Token — Web3 Pet Game

**My Pet Token** คือเกมเลี้ยงสัตว์เสมือนจริงแบบ Web3 ที่มุ่งเน้นความโปร่งใสและ Decentralized โดยใช้ **PET Token (ERC-20)** เป็นสกุลเงินหลักเพียงเหรียญเดียวในระบบ ทั้งสำหรับจ่ายเป็นรางวัลทำภารกิจและใช้ซื้อไอเทมภายในเกม[cite: 1]

---

## 📌 1. สถาปัตยกรรมระบบ (System Architecture)

ระบบแบ่งการจัดการ Wallet และการไหลของข้อมูลออกเป็น 2 ส่วนหลัก:
* **Wallet A (Admin / Treasury Wallet):** กระเป๋าของผู้ดูแลระบบที่เป็นผู้ถือครอง PET Token ทั้งหมดในตอนเริ่มต้น ทำหน้าที่ฝากเหรียญสำรองเข้าสู่ระบบกองทุนแจกรางวัล[cite: 1]
* **Wallet B (Player / MetaMask Wallet):** กระเป๋าของผู้เล่นที่เชื่อมต่อเข้ากับเว็บไซต์ เพื่อรับโอนเหรียญ PET Token อัตโนมัติเมื่อทำภารกิจสำเร็จ และใช้เหรียญของตนเองในการอนุมัติสิทธิ์ (`approve`) และชำระเงินค่าไอเทม[cite: 1]

---

## 📜 2. สรุปการทำงานของ Smart Contracts

โปรเจกต์นี้เขียนด้วยภาษา Solidity และประกอบด้วย 3 สัญญาหลักที่ทำงานร่วมกัน:[cite: 1]

* **`PETToken.sol` (ระบบเหรียญโทเคน):** 
  สัญญาสร้างเหรียญมาตรฐาน ERC-20 ทำหน้าที่กำหนดชื่อย่อ (PET) จัดการจำนวนเหรียญเริ่มต้นทั้งหมด (Initial Supply) และมีฟังก์ชันการสร้างเหรียญเพิ่มที่ควบคุมโดยเจ้าของระบบ[cite: 1]

* **`RewardContract.sol` (ระบบคลังรางวัล):** 
  สัญญากองทุนที่รับเหรียญสำรองมาจาก Admin และทำหน้าที่จ่ายรางวัลอัตโนมัติ (กำหนดเรทไว้ที่ 10 PET ต่อภารกิจ) ให้แก่ผู้เล่นเมื่อทำภารกิจสำเร็จ พร้อมมีระบบบันทึกสถานะเพื่อป้องกันไม่ให้ผู้เล่นกดรับรางวัลจากภารกิจเดิมซ้ำ[cite: 1]

* **`ShopContract.sol` (ระบบร้านค้าในเกม):** 
  สัญญาที่ทำหน้าที่จัดเก็บรายการสินค้า ไอเทม (เช่น อาหาร เครื่องแต่งกาย) และจัดการระบบซื้อขาย โดยจะตรวจสอบยอดเงินของผู้เล่น จากนั้นดึงเหรียญ PET จากกระเป๋าผู้เล่นมายังร้านค้าผ่านฟังก์ชันการโอนอย่างปลอดภัย พร้อมบันทึกข้อมูลไอเทมลงในคลังของผู้เล่น[cite: 1]

## 🎨 3. ระบบแสดงผล (Canvas Animation Engine)

* **HTML5 Canvas:** ใช้สำหรับเรนเดอร์กราฟิกตัวละครสัตว์เลี้ยงแบบสตรีมเคลื่อนไหวตลอดเวลา 60 FPS[cite: 1]
* **Coordinate Matrix:** มีระบบคำนวณพิกัดตำแหน่งทางเรขาคณิตของชิ้นส่วนร่างกาย (เช่น หัว ลำตัว หู ตา จมูก) และตำแหน่งสวมใส่ไอเทมตกแต่ง (เช่น หมวก แว่นตา) บนพื้นที่ Canvas ขนาด `400x400` พิกเซลได้อย่างแม่นยำ[cite: 1]

## 📋 4. ระบบภารกิจและรางวัล (Mission System)

เมื่อผู้เล่นทำกิจกรรมหรือภารกิจภายในเกมสำเร็จ (เช่น การเช็คอินประจำวัน การให้อาหาร การเล่นกับสัตว์เลี้ยง และการซื้อไอเทม) ระบบจะเปิดให้ผู้เล่นกดปุ่มเคลมเพื่อรับ **10 PET Token** ซึ่งตัวสัญญาอัจฉริยะจะทำการโอนเหรียญเข้าสู่กระเป๋า MetaMask ของผู้เล่นบนบล็อกเชนจริงทันที[cite: 1]

---

## 🛠️ 5. วิธีการใช้งานและการทดสอบ (Getting Started)

1. **Deploy Smart Contracts:** นำโค้ดสัญญาอัจฉริยะทั้ง 3 ไป Deploy บนเครือข่าย Testnet ผ่านเครื่องมือ Remix IDE[cite: 1]
2. **Setup Reserve:** โอนเหรียญ PET จากกระเป๋า Admin เข้าไปยังสัญญา `RewardContract` เพื่อจัดตั้งเป็นกองทุนสำรองสำหรับแจกรางวัล[cite: 1]
3. **Configure Frontend:** นำ Address ของสัญญาอัจฉริยะที่ Deploy แล้วไปอัปเดตใส่ในไฟล์เชื่อมต่อฝั่งเว็บไซต์ (Frontend)[cite: 1]
4. **Play Game:** เปิดใช้งานเว็บไซต์ เชื่อมต่อกระเป๋า MetaMask เล่นเกม ทำภารกิจ และกดรับเหรียญรางวัลเข้ากระเป๋าจริงได้ทันที[cite: 1]
