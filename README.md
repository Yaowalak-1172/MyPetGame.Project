# 🐾 My Pet Token — Web3 Pet Game

**My Pet Token** คือเกมเลี้ยงสัตว์เสมือนจริงแบบ Web3 ที่มุ่งเน้นความโปร่งใสและ Decentralized โดยใช้ **PET Token (ERC-20)** เป็นสกุลเงินหลักเพียงเหรียญเดียวในระบบ ทั้งสำหรับจ่ายเป็นรางวัลทำภารกิจและใช้ซื้อไอเทมภายในเกม

---

## 📌 1. สถาปัตยกรรมระบบ (System Architecture)

ระบบแบ่งการจัดการ Wallet และการไหลของข้อมูลออกเป็น 2 ส่วนหลัก:
* **Wallet A (Admin / Treasury Wallet):** กระเป๋าของผู้ดูแลระบบที่เป็นผู้ถือครอง PET Token ทั้งหมดในตอนเริ่มต้น ทำหน้าที่ฝากเหรียญสำรองเข้าสู่ระบบกองทุนแจกรางวัล
* **Wallet B (Player / MetaMask Wallet):** กระเป๋าของผู้เล่นที่เชื่อมต่อเข้ากับเว็บไซต์ เพื่อรับโอนเหรียญ PET Token อัตโนมัติเมื่อทำภารกิจสำเร็จ และใช้เหรียญของตนเองในการอนุมัติสิทธิ์ (`approve`) และชำระเงินค่าไอเทม

---

## 📜 2. สรุปการทำงานของ Smart Contracts

โปรเจกต์นี้เขียนด้วยภาษา Solidity และประกอบด้วย 3 สัญญาหลักที่ทำงานร่วมกัน

* **`PETToken.sol` (ระบบเหรียญโทเคน):** 
  สัญญาสร้างเหรียญมาตรฐาน ERC-20 ทำหน้าที่กำหนดชื่อย่อ (PET) จัดการจำนวนเหรียญเริ่มต้นทั้งหมด (Initial Supply) และมีฟังก์ชันการสร้างเหรียญเพิ่มที่ควบคุมโดยเจ้าของระบบ

* **`RewardContract.sol` (ระบบคลังรางวัล):** 
  สัญญากองทุนที่รับเหรียญสำรองมาจาก Admin และทำหน้าที่จ่ายรางวัลอัตโนมัติ (กำหนดเรทไว้ที่ 10 PET ต่อภารกิจ) ให้แก่ผู้เล่นเมื่อทำภารกิจสำเร็จ พร้อมมีระบบบันทึกสถานะเพื่อป้องกันไม่ให้ผู้เล่นกดรับรางวัลจากภารกิจเดิมซ้ำ

* **`ShopContract.sol` (ระบบร้านค้าในเกม):** 
  สัญญาที่ทำหน้าที่จัดเก็บรายการสินค้า ไอเทม (เช่น อาหาร เครื่องแต่งกาย) และจัดการระบบซื้อขาย โดยจะตรวจสอบยอดเงินของผู้เล่น จากนั้นดึงเหรียญ PET จากกระเป๋าผู้เล่นมายังร้านค้าผ่านฟังก์ชันการโอนอย่างปลอดภัย พร้อมบันทึกข้อมูลไอเทมลงในคลังของผู้เล่น

---

## 🎨 3. ระบบแสดงผล (Canvas Animation Engine)

* **HTML5 Canvas:** ใช้สำหรับเรนเดอร์กราฟิกตัวละครสัตว์เลี้ยงแบบสตรีมเคลื่อนไหวตลอดเวลา 60 FPS
* **Coordinate Matrix:** มีระบบคำนวณพิกัดตำแหน่งทางเรขาคณิตของชิ้นส่วนร่างกาย (เช่น หัว ลำตัว หู ตา จมูก) และตำแหน่งสวมใส่ไอเทมตกแต่ง (เช่น หมวก แว่นตา) บนพื้นที่ Canvas ขนาด `400x400` พิกเซลได้อย่างแม่นยำ

---

## 📋 4. ระบบภารกิจและรางวัล (Mission System)

เมื่อผู้เล่นทำกิจกรรมหรือภารกิจภายในเกมสำเร็จ (เช่น การเช็คอินประจำวัน การให้อาหาร การเล่นกับสัตว์เลี้ยง และการซื้อไอเทม) ระบบจะเปิดให้ผู้เล่นกดปุ่มเคลมเพื่อรับ **10 PET Token** ซึ่งตัวสัญญาอัจฉริยะจะทำการโอนเหรียญเข้าสู่กระเป๋า MetaMask ของผู้เล่นบนบล็อกเชนจริงทันที

---

## 🎮 5. คู่มือและวิธีการเล่นเกม (Gameplay Guide)

1. **เชื่อมต่อกระเป๋าเงิน (Connect Wallet):** เข้าสู่เว็บไซต์เกมแล้วคลิกปุ่มเชื่อมต่อกระเป๋า (Connect MetaMask) เพื่อให้ระบบอ่านที่อยู่กระเป๋า (Wallet B) และตรวจสอบยอดเหรียญ PET
2. **เลือกสัตว์เลี้ยงและดูแล (Pet Care):** ผู้เล่นสามารถเลือกสัตว์เลี้ยง (เช่น คาปิบาร่า) และคอยดูแลความสะอาด ให้อาหาร หรือเล่นด้วยกัน เพื่อรักษาสถานะความหิว (Hunger) และความสุข (Happiness) ของสัตว์เลี้ยงให้อยู่ในระดับที่ดี
3. **การทำภารกิจ (Missions):** ภายในเกมจะมีระบบภารกิจต่างๆ ให้ทำ (เช่น เช็คอินประจำวัน, ให้อาหาร, เล่นกับสัตว์เลี้ยง, ซื้อไอเทม) เมื่อทำสำเร็จจะสามารถกดปุ่ม **Claim Reward** บนหน้าจอ
4. **รับเหรียญรางวัล (Auto-Reward):** ระบบ Smart Contract จะทำการโอนเหรียญรางวัล 10 PET เข้าสู่กระเป๋า MetaMask ของผู้เล่นบนบล็อกเชนโดยอัตโนมัติทันที
5. **ซื้อไอเทมแต่งตัว (Item Shop):** นำเหรียญ PET ที่ได้รับจากการทำภารกิจไปเลือกซื้อไอเทมพิเศษ เช่น อาหารพรีเมียม แว่นตา หมวก หรือมงกุฎ เพื่อนำมาตกแต่งสัตว์เลี้ยงและเพิ่มความสามารถในเกม

---

## 🛠️ 6. วิธีการใช้งานและการทดสอบ (Getting Started)

1. **Deploy Smart Contracts:** นำโค้ดสัญญาอัจฉริยะทั้ง 3 ไป Deploy บนเครือข่าย Testnet ผ่านเครื่องมือ Remix IDE
2. **Setup Reserve:** โอนเหรียญ PET จากกระเป๋า Admin เข้าไปยังสัญญา `RewardContract` เพื่อจัดตั้งเป็นกองทุนสำรองสำหรับแจกรางวัล
3. **Configure Frontend:** นำ Address ของสัญญาอัจฉริยะที่ Deploy แล้วไปอัปเดตใส่ในไฟล์เชื่อมต่อฝั่งเว็บไซต์ (Frontend)
4. **Play Game:** เปิดใช้งานเว็บไซต์ เชื่อมต่อกระเป๋า MetaMask เล่นเกม ทำภารกิจ และกดรับเหรียญรางวัลเข้ากระเป๋าจริงได้ทันที
